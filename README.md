## 🚀 What I'm building

### [LocalCloud — local.cloud](https://local.cloud)

A local cloud environment for developers and AI coding agents to build, test, and debug Google Cloud applications. Google Cloud-compatible services run in one Docker container, with familiar SDKs, a CLI, a web console, and MCP integration.

The goal: a fast, repeatable development loop for applications, integration tests, and CI, without waiting for a cloud project or paying for Google Cloud resources during local testing.

[CLI & releases](https://github.com/LocalGCloud/localcloud-cli) · [Documentation](https://local.cloud/docs/) · [AI agents & MCP](https://local.cloud/docs/mcp/)

### [Data Oculus — dataoculus.app](https://dataoculus.app)

Building self-service, real-time data reliability across streaming and batch systems. My focus is detecting problems close to the source through data profiling, schema-drift detection, executable data contracts, and AI-assisted quality rules.

[Explore Data Oculus](https://dataoculus.app) · [Documentation](https://dataoculus.app/docs/intro/)

## 🏗️ Engineering at PayPal

I work at the intersection of platform architecture, hands-on engineering, and technical leadership, with a focus on business enablement, adoption, reliability, and cost.

- **Data movement:** Building and evolving enterprise data integration using Apache Airflow and Apache Gobblin, in a data ecosystem spanning hundreds of petabytes.
- **Governed data foundations:** Data scanning, cataloging, metadata, and self-service capabilities that help teams discover and use data responsibly.
- **Real-time systems:** Event collection, streaming pipelines, and analytics infrastructure that connect data producers with downstream consumers.
