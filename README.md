## 🏗️ Engineering at PayPal

I work at the intersection of platform architecture, hands-on engineering, and technical leadership, with a focus on business enablement, adoption, reliability, and cost.

- **Data movement:** Building and evolving enterprise data integration using Apache Airflow and Apache Gobblin, in a data ecosystem spanning hundreds of petabytes.
- **Governed data foundations:** Data scanning, cataloging, metadata, and self-service capabilities that help teams discover and use data responsibly.
- **Real-time systems:** Event collection, streaming pipelines, and analytics infrastructure that connect data producers with downstream consumers.
